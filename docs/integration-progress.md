## Decisions and completed gates

1. **Baseline and harness:** frozen source and first-run logs retained; CPU metadata-path correction recorded separately. Capability manifests record versions, source hashes, UUIDs/topology and selected environment. CUDA requirements fail rather than silently falling back. GPU experiments were serialized under the primary coordinator.
2. **DDP before layout promotion:** two-/four-rank contiguous AMP/AdaGC runs passed four cases of 204 attempts each (201 successes plus three overflow skips for AMP). Independent full-batch/norm oracles, uneven-count weighting and unsafe scaler/post-reduction-nonfinite negative probes passed. Four-rank channels-last passed the same cases. Additional two-/four-rank unused-branch, late activation, dormant-parameter and actual input-exhaustion probes passed.
3. **Layout/state:** canonical row-major state and checkpoint v3 implemented; original storage/gradient preservation, cross-layout load, strict arithmetic and stream/lifetime tests passed. Dedicated CUDA layout matrix: 130 passed. Staging overhead measured at 2–14%, no persistent FP32 shadow for FP32 weights. Overlap and stepped holes remain rejected.
4. **Paging:** inspection of the pinned allocator and seven CUDA binaries found no owned storage deleter/release interface. Eligible native paging is explicitly refused before updates/load transfer. Ordinary CPU/subthreshold controls and rejection tests pass. Managed lifetime/residency/migration/DDP restore cannot be qualified until this prerequisite is solved; no unsafe allocator patch was applied.
5. **Compilation:** actual Inductor FP32 model fixtures and short two-/four-rank DDP smoke passed. Actual FP16 fixtures failed their fixed numerical gates; identical compiled-gradient optimizer replay remains exact. Partial optimizer Dynamo capture is explicitly interpreter-backed, with no native performance claim. Fullgraph/CUDA graphs remain unsupported.
6. **Recovery:** CPU six-fault trainer rollback, actual two-/four-worker SIGKILL, prefetch/persistence variants, two-rank Gloo and optional StatefulDataLoader iterable replay passed within scope. CUDA four-rank trainer rollback, two-rank loader-child failure, physical GPU remap, transposed AMP restart, four-rank channels-last AMP restart, and native FP32 Inductor fresh-cache recovery passed. Rank-local buffers and next RNG draws are compared. Fixed world size and replayable data remain required.
7. **FP8:** SM75 negative gate and mocked availability API tests passed. Optional Transformer Engine example illustrates FP32 optimizer-facing state. Positive FP8, torchao, amax/cache/quality/DDP/recovery experiments require suitable hardware and backend-specific tests; availability remains unqualified.
8. **Regression/performance/documentation:** full CUDA-required, installed-wheel CPU, six independent CUDA gates, build/metadata and lint checks are recorded in the final report. The balanced 54-process campaign completed 16,200 timed updates: five paired +10% upper slowdown bounds passed, single-GPU strong scaling remains inconclusive. The existing application-quality interval remains inconclusive; a three-seed 200-step AdaGC CPU replay matches baseline bitwise. README presents current behavior and limitations. Manual trusted four-GPU CI is configured; hosted CPU CI is separate.

## Evidence corrections and review resolution

- An initial direct-P2P DDP run was interrupted without a verdict. Passing local runs explicitly use `NCCL_P2P_DISABLE=1`/SHM. This is not a diagnosis of the interrupted run.
- A replay clone changed gradient alignment and therefore a foreach norm by one ULP. Alignment-preserving replay retains exact assertions; optimizer arithmetic and tolerances were not weakened.
- The first performance schedule tried baseline channels-last, which that baseline rejects. Final paired comparisons use contiguous layouts; new channels-last arms are descriptive. Both campaign records are retained.
- Independent review reproduced incorrect unwrapping of ordinary models with a child named `module`. Recognized wrapper types and a red-to-green regression preserve all model state. Directory fsync, distinct rank buffers and collective rollback for component-load errors are tested.
- Installed-wheel testing from `/tmp` exposed a pytest subprocess relying on its working directory. Setting its repository cwd loads the intended custom option; failed and passing logs are preserved. No optimizer change was required.

These outcomes close the planned investigation with explicit failures/blocks; they do not claim universal support for every cross-product of features.
